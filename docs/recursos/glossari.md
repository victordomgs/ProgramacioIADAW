# Glossari

Termes clau del mòdul. Afegiu-ne de nous en ordre alfabètic.

Embedding
:   Representació d'un text, imatge o altre contingut com a vector numèric, de manera que continguts semblants queden a prop a l'espai vectorial.

LLM (*Large Language Model*)
:   Model de llenguatge de grans dimensions entrenat per generar i interpretar text.

Prompt engineering
:   Disseny i optimització de les instruccions (*prompts*) que s'envien a un model per obtenir-ne respostes més precises i útils.

Prompt injection
:   Atac que consisteix a introduir instruccions malicioses en l'entrada d'un model per alterar-ne el comportament previst.

RAG (*Retrieval-Augmented Generation*)
:   Tècnica que combina la recuperació d'informació rellevant (normalment amb cerca vectorial) amb la generació de text d'un LLM.

System prompt
:   Instruccions de context que defineixen el rol, el to i les restriccions d'un model o agent abans de la conversa amb l'usuari.
