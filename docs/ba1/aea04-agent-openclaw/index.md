Creació d'agents mitjançant les tècniques de *system prompt* treballades anteriorment.

[:material-file-word: Descarrega el document de l'activitat (.docx)](fitxers/DAW_M0617_BA1-AEA4_Agent_camp_OpenClaw_2026-27.docx){ .md-button .md-button--primary }

## Objectius

1. Entendre com el procés central **Gateway** orquestra diferents agents amb espais de treball (*workspaces*) i sessions d'usuari aïllades.
2. Aplicar el **principi de mínim privilegi** configurant quins agents tenen accés a l'eina d'execució de comandes (`exec`) i establir entorns aïllats (*sandboxing*).
3. Configurar el connector d'un **servei de missatgeria** i definir regles d'enrutament de canals (*channel-routing*) per vincular la plataforma de missatgeria amb un agent específic.
4. **Verificar** la restricció de permisos, gestionar les sol·licituds d'emparellament d'usuaris i inspeccionar els registres d'auditoria del Gateway.

!!! tip "Teoria"
    Vegeu [6. Orquestració d'agents amb OpenClaw](../teoria/06-openclaw.md) per a l'arquitectura del Gateway i la configuració d'OpenClaw.
